# Unified drawing and modeling workspace

Make threeditor a coherent Blender-style editor for interactive Three.js scenes, with a shared modeling workflow and one drawing surface for editable curves and strokes, texture paint and splat paint. Use Unity-style object components for JavaScript authoring and keep Three.js as the runtime for Play and publishing.

The [acceptance criteria](facts.md) define the outcomes. The [execution plan](plan.md) defines the order of work and verification. The user requested independent setup, so the initial scope and decisions were derived from the brief and repository inspection. The plan and criteria are available for review together.

Done when the acceptance criteria are verified, the integrated authoring walkthrough passes, and the baseline sample projects still reopen and play.
